# WordSeed — CSV 단어 학습 앱

CSV 파일을 업로드해 단어장을 만들고, 플래시카드와 객관식 퀴즈로 학습하는 바닐라 JavaScript 앱입니다.

## 실행 방법

별도 설치나 빌드 과정이 없습니다.

1. 압축을 풉니다.
2. `index.html` 파일을 Chrome, Edge, Safari 또는 Firefox에서 엽니다.
3. 기본 샘플 단어장으로 바로 체험하거나 `CSV 업로드`에서 파일을 추가합니다.

> 브라우저 보안 설정에 따라 로컬 파일에서 일부 기능이 제한되면 간단한 로컬 서버를 사용할 수 있습니다.
>
> Python이 설치되어 있다면 폴더에서 다음 명령을 실행합니다.
>
> ```bash
> python -m http.server 8000
> ```
>
> 이후 브라우저에서 `http://localhost:8000`으로 접속합니다.

## CSV 형식

필수 열은 `어휘`, `뜻`이며 `품사`는 선택 사항입니다.

```csv
어휘,품사,뜻
improve,v.,향상하다
keep,phr.,"a journal 일지를 쓰다, 기록을 남기다"
matter,v.,중요하다
reflect,phr.,on ~을 되돌아보다
```

- 한글 깨짐 방지를 위해 UTF-8을 권장합니다.
- 쉼표가 포함된 값은 큰따옴표로 감쌉니다.
- `단어`, `영어`, `word`, `vocabulary`도 어휘 열로 인식합니다.
- `의미`, `해석`, `meaning`, `definition`도 뜻 열로 인식합니다.
- 쉼표, 탭, 세미콜론 구분자를 자동 감지합니다.
- 최대 업로드 파일 크기는 5MB입니다.

## 구현 기능

- CSV 드래그 앤 드롭 및 파일 선택
- 업로드 미리보기와 행별 오류 검사
- 중복 단어 제외
- 여러 단어장 생성 및 전환
- 단어 직접 추가·수정·삭제·검색·필터
- 플래시카드 뒤집기와 학습 난이도 평가
- 브라우저 음성 합성을 이용한 영어 발음
- 영어→뜻, 뜻→영어, 혼합 객관식 퀴즈
- 정답률, 암기 상태, 어려운 단어, 퀴즈 기록 통계
- LocalStorage 자동 저장
- 모바일 반응형 레이아웃

## 파일 구성

- `index.html`: 앱 화면 구조
- `styles.css`: 전체 디자인과 반응형 스타일
- `app.js`: CSV 처리, 단어장, 학습, 퀴즈, 통계 로직
- `sample-vocabulary.csv`: 업로드 테스트 파일

## 데이터 저장

모든 데이터는 사용자의 브라우저 LocalStorage에 저장됩니다. 서버로 전송되지 않습니다.

브라우저 데이터 삭제, 시크릿 모드 종료 또는 다른 기기 사용 시 데이터가 유지되지 않을 수 있습니다.
